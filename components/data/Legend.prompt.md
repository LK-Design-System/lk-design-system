**Legend** — 맵·차트·다이어그램용 색상 키(스와치 + 라벨).

```jsx
<Legend items={[
  { label: '가용', color: 'var(--color-semantic-status-positive)', shape: 'dot' },
  { label: '경로', color: 'var(--color-semantic-primary-normal)', shape: 'line' },
]} />
```

- **items** `{label,color,shape,value,muted}[]` · **direction** `horizontal · vertical` · shape `dot · line · square`.
