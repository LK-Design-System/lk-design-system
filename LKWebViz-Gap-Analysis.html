실제 프론트엔드 LK-ROBOTICS/lk_web_viz의 컴포넌트를 전수 분석해, LK 디자인 시스템이 덮는 영역과 덮지 못하는 요소를 정리했습니다. 결론부터: 제네릭 UI 크롬(폼·오버레이·피드백·데이터·내비)은 DS로 충분히 대체 가능하고, 미커버는 전부 로보틱스 도메인 뷰어·에디터·컨트롤입니다.

◆ 제네릭 UI = 커버 · 로보틱스 도메인 프리미티브 = 신규 필요

03 미커버 갭 — 로보틱스 도메인

DS에 없음. 우선순위 P1(재사용·빈도 높음) → P3

P1 2D 맵 캔버스 뷰어

occupancy grid / PGM 렌더 + 팬·줌 + 오버레이(로봇 포즈·경로·존·웨이포인트·랜드마크). Map2DViewer · MapPreview · CityMapView · SiteStructureCanvas (konva)

P1 3D 씬 뷰어 프레임

three/fiber 캔버스 셸 + 카메라/그리드/조명 프리셋. 포인트클라우드·TF 축·로봇 모델·플로어/빌딩. PointCloudViewer · TFViewer · StructurePreviewViewer · FloorScene3D · Building3DView · SiteStructurePreview3D

P1 맵/지오메트리 에디터 툴

PGM 픽셀 편집, Zone 폴리곤 그리기, 랜드마크·웨이포인트·레인 편집, 편집 툴바 + undo/redo. PgmEditor · ZoneEditor · PcdMap3DPanel · useHistory

P1 텔레옵 컨트롤 — 조이스틱

가상 조이스틱 / D-패드 / 속도 슬라이더. controls/Joystick

P1 로봇 상태 카드 (라이브)

포즈·배터리·연결·모드를 실시간 바인딩. DS Card+StatusBadge로 셸은 되나 배터리 게이지·라이브 데이터 패턴이 없음. RobotCard

P2 ROS/토픽 · TF 트리

토픽 계층·구독 관리·TF 변환 트리. DS Tree 기반이나 ROS 특화 셀(타입·헤르츠·구독 토글)이 필요. TopicTreeModal · TFTreeList · SubscribedTopicList · useTFTree

P2 연결 · 텔레메트리 인디케이터

MQTT / rosbridge 연결 상태, 신호 세기, 하트비트. mqtt · rosbridge_client

P2 빌딩/사이트 토폴로지

플로어 셀렉터·휠 피커, 레인/웨이포인트 상세 패널, 캠퍼스 오버뷰, 노드-엣지 토폴로지 그래프, FM 스타일 뷰. FloorSelector · FloorWheelPicker · LaneDetailPanel · WaypointDetailPanel · CampusOverview · BuildingTopology(3D/FM)View

P2 태스크 시퀀스 빌더 · 라이브 런

스텝 시퀀스 편집(드래그·추가) + 맵 위 실시간 실행 상태. TaskCreate/RunScreen · AddWaypointDialog

P2 Rerun 뷰어 임베드 래퍼

@rerun-io/web-viewer 마운트 셸 + 로딩/에러 상태. RerunViewer

P3 짐벌 팬/틸트 컨트롤

2축 팬-틸트 패드 + 각도 리드아웃. GremsyGimbalScreen

P3 Nav 튜닝 · 커브 피팅 UI

파라미터 그룹 + 곡선 그래프. NavTuningScreen · curve_fitting

P3 계측 입력 · 게이지

미터/각도 입력, 맵 스케일·그리드 눈금, 배터리·속도 게이지(DS Meter·CircularProgress 있으나 telemetry 특화 아님).

04 파운데이션 갭

  • 아이콘 — app은 Material Icons + 도메인 SVG(robot·map·task·warning…). 우리 Icon(Lucide 62종)엔 로보틱스 글리프가 부족 → 세트 확장 필요.
  • 색/테마 — app의 constants/colors.ts + ThemeContext를 DS 시맨틱 토큰(라이트/다크)으로 정렬·통합하면 중복 제거.

05 권고

  • 즉시 교체 — 폼·오버레이·피드백·데이터·내비의 인라인 커스텀을 DS 컴포넌트로 치환해 중복 제거(가장 빠른 ROI).
  • 신규 그룹 신설 — DS에 로보틱스 프리미티브 그룹 추가 검토: viz/(Map2DCanvas, Scene3DFrame, TelemetryGauge), robotics/(Joystick, RobotStatusCard, ConnectionBadge, TopicTree), editor/(CanvasEditorShell, ZoneToolbar, HistoryToolbar). 무거운 렌더 로직은 app에 두고, DS는 셸·툴바·패널·토큰을 표준화.
  • 아이콘 세트 확장 — robot · map-pin · waypoint · lidar · battery · joystick 등 도메인 글리프 추가.
  • 토큰 정렬 — colors.ts → DS 토큰 매핑 후 단일 소스화.
