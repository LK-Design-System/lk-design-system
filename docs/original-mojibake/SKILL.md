먼저 이 스킬의 `readme.md`를 읽으세요 — 브랜드 맥락, 콘텐츠 보이스, 비주얼 파운데이션
요약, 아이코노그래피 규칙, 컴포넌트 매니페스트가 들어 있습니다(값의 단일 소스는
`tokens/`와 `guidelines/` 카드). 그런 다음 다른 파일을 살펴보세요:

- `styles.css` + `tokens/` — 전역 스타일시트와 모든 디자인 토큰(색상, 타입,
  스페이싱, 효과). 브랜드를 상속하려면 `styles.css`를 링크하세요.
- `guidelines/` — 파운데이션 스펙시멘 카드(색상, 타이포그래피, 스페이싱, 브랜드).
- `components/` — 재사용 React 프리미티브(Button, Input, Tag, Card,
  ProductCard, TopBar, Lockup, NewsCard, …). 각각 `.jsx`, `.d.ts` props 계약,
  `.prompt.md` 사용 노트를 가집니다.
- `assets/` — 브랜드 로고, 파비콘 모노그램, 샘플 제품/산업/기술 사진. 필요한 것을
  복사하세요; 로고나 아이콘은 다시 그리지 마세요.
- `COVERAGE.md` · `LK-DS-Adoption-Guide.html` — 킷 커버리지·컴포넌트 이름 근거, 그리고
  실제 앱 채택·토큰 매핑·남은 결정. 왜 이렇게 이름/구성했는지 궁금할 때 참고.

비주얼 산출물(슬라이드, 목업, 일회성 프로토타입, 소셜 게시물)을 만들 때는 `assets/`에서
필요한 에셋을 복사하고 사용자가 볼 수 있는 정적 HTML 파일을 만드세요. 프로덕션 코드
작업이라면 에셋을 복사하고 여기 토큰 CSS + 규칙을 적용해 브랜드로 네이티브하게
디자인하세요.

핵심 브랜드 요점: 이중 언어 한국어 우선 카피(한국어는 `word-break: keep-all` 사용);
모든 텍스트에 **Pretendard JP**(오프라인 포함, 디스플레이까지); 브랜드 **네이비
`#0E1329`** 잉크 + 다크 서피스; 단 하나의 **시그널**(다크에 스틸 블루 `#4E7CA8` /
라이트에 딥 틸 `#0B798A`) — 이브로우·링크·활성 상태·아이콘용; **그래파이트 `#2C3547`**
세컨더리 버튼, 애저 `#0067A8` 프라이머리; 차분한 상태색; 부드러운 네이비 틴트 그림자;
모션(120/200/320ms); Lucide 라인 아이콘; 이모지 없음.

사용자가 다른 지침 없이 이 스킬을 부르면, 무엇을 만들거나 디자인하고 싶은지 묻고, 몇
가지 초점 있는 질문을 한 뒤, 필요에 따라 HTML 산출물 _또는_ 프로덕션 코드를 내놓는 전문
LK ROBOTICS 디자이너로 행동하세요.
