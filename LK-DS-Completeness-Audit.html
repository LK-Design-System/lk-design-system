Starting Point · UI 킷

이 디자인 시스템은 ui_kits/ 폴더가 없고, 컴포넌트 .d.ts나 화면 HTML 어디에도 @startingPoint 태그가 없습니다(check_design_system 확인: Starting points / Templates 모두 "none"). 즉 소비 프로젝트가 "여기서부터 시작"할 수 있는 완성 화면이 하나도 없고, 141개 컴포넌트를 전부 손으로 조립해야 합니다. 사용자 결정으로 이번 라운드는 보류합니다 — 나머지 항목이 먼저 정리된 뒤 착수하기로 했습니다.

브랜드에는 실제 제품이 5종(assets/products/ — S1·T1·CP·SSAI·VisionX)이고 실전 감사 대상 앱도 2개나 있었던 만큼, 제품 소개 화면 1개 + 관제 대시보드 화면 1개 정도를 UI 킷으로 완성해두면 이 레이어의 공백이 바로 메워집니다.
